### Data Structures:
- Binary heap data structures: priority queue
- Statically balanced BST (Binary Search Tree): Fenwick and segment trees
- Balanced BST: problems will not be designed to distinguish between the implementation of BBSTs, such as treaps, splay trees, AVL trees, or scapegoat trees 
- Augmented BST: extra information is stored and maintained at each node
- Decomposition of Static Trees (heavy-light, separator structures: centroid decomposition)
- Persistent data structures: problems should not attempt to distinguish between implementation techniques. In particular, implementation by path copying should be sufficient.
